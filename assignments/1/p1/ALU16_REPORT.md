# ALU16 设计与仿真报告（更新）

## 1. 设计概述

该项目实现了一个 16-bit 算术逻辑单元（ALU），支持 8 种操作：加法、减法、按位与、按位或、按位异或、逻辑左移、逻辑右移和无符号比较。ALU 通过 3-bit 操作码选择对应操作，并根据操作类型输出结果和相关标志位。

### 操作码映射表

| 操作码 | 操作 | 功能 | Carry/Overflow 说明 |
|--------|------|------|-------------------|
| `3'b000` | ADD | 无符号加法 | carry：进位；overflow：有符号溢出 |
| `3'b001` | SUB | 无符号减法 | carry：无借位指示；overflow：有符号溢出 |
| `3'b010` | AND | 按位与 | carry=0, overflow=0 |
| `3'b011` | OR | 按位或 | carry=0, overflow=0 |
| `3'b100` | XOR | 按位异或 | carry=0, overflow=0 |
| `3'b101` | SLL | 逻辑左移 | carry=0, overflow=0 |
| `3'b110` | SRL | 逻辑右移 | carry=0, overflow=0 |
| `3'b111` | CMPU | 无符号比较 | carry=0, overflow=0 |

## 2. 标志位详解

### 2.1 `zero` 标志（1-bit）

- **含义**：表示 ALU 运算结果是否为 0
- **触发条件**：`zero = (result == 16'h0000)`
- **用途**：条件分支、循环控制（如检测数组末尾或计数器清零）
- **示例**：
  - `0x0003 + 0x0005 = 0x0008` → `zero=0`（结果非零）
  - `0x0005 - 0x0005 = 0x0000` → `zero=1`（结果为零）

### 2.2 `negative` 标志（1-bit）

- **含义**：表示 ALU 运算结果的符号位（最高位 MSB）
- **触发条件**：`negative = result[15]`
- **解释**：在补码表示中，MSB=1 表示负数（有符号视角）；MSB=0 表示非负数
- **用途**：分支判断、符号检测（配合其他标志进行有符号数比较）
- **示例**：
  - `0x7FFF + 0x0001 = 0x8000` → `negative=1`（MSB=1，有符号视角为负数）
  - `0x0003 + 0x0005 = 0x0008` → `negative=0`（MSB=0，非负）

### 2.3 `carry` 标志（1-bit）

**只对加法和减法有意义；其他操作默认为 0**

#### 加法中的 `carry`（无符号进位）

- **定义**：从 16-bit 加法进位到第 17-bit 的标志
- **计算**：使用 17-bit 中间结果：`carry = sum_u[16]`，其中 `sum_u = {1'b0, a} + {1'b0, b}`
- **含义**：指示无符号加法的结果是否超过 16-bit 最大值（65535）
- **示例**：`0xFFFF + 0x0001 = 0x0000 (carry=1)`

#### 减法中的 `carry`（无借位指示）

- **定义**：表示是否发生无符号借位（即 `a >= b` 的判定）
- **计算**：`carry = sub_u[16]`，其中 `sub_u = {1'b0, a} + {1'b0, (~b)} + 1`（两进制补码减法）
- **含义**：`carry=1` 表示 `a >= b`（无借位）；`carry=0` 表示 `a < b`（有借位）
- **示例**：
  - `0x0008 - 0x0003 = 0x0005 (carry=1)`（8 >= 3）
  - `0x0005 - 0x0005 = 0x0000 (carry=1)`（5 >= 5）

---

### 2.4 `overflow` 标志（1-bit）

- **含义**：表示有符号（补码）运算是否发生溢出，仅对加法和减法有意义；其它操作的 `overflow` 恒为 0。
- **触发条件**：当有符号补码运算结果超出表示范围（-32768 ~ 32767）时置位。

- **加法中的溢出检测**：

```
overflow = (a[15] == b[15]) && (result[15] != a[15])
```

- **逻辑**：同号数相加若结果符号发生变化则发生溢出。
- **示例**：
  - `0x7FFF (32767) + 0x0001 (1) = 0x8000 (-32768 in signed)` → `overflow=1`
  - `0x8000 (-32768) + 0x8000 (-32768) = 0x0000` → `overflow=1`

- **减法中的溢出检测**：

```
overflow = (a[15] != b[15]) && (result[15] != a[15])
```

- **逻辑**：异号数相减若结果符号与被减数不同则发生溢出。

（注：无符号运算的进位与有符号溢出是不同概念；本设计中 `overflow` 仅反映有符号溢出行为。）
